# Emakefun NLCS21 颜色传感器 (`emakefun_color_nlcs21`)

Emakefun NLCS21 I2C 颜色识别传感器，支持多档增益、积分时间、颜色采样与阈值中断。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/smart_modules/color_recognition/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_color_sensor_nlcs21
- 积木数量：6 块（CK `schema v2` 声明式运行时）
