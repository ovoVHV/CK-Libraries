# Emakefun 触摸矩阵键盘 V3 (`emakefun_matrix_kbd_v3`)

Emakefun 4×4 I2C 触摸矩阵键盘 V3.0（默认地址 0x65），内置软件消抖，支持按下/按住/松开事件与字符读取。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/base_modules/matrix_keyboard_module_v3.0/README/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_matrix_keyboard_v3
- 积木数量：5 块（CK `schema v2` 声明式运行时）
