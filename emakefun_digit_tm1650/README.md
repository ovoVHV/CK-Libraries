# Emakefun 四位数码管 V1 (`emakefun_digit_tm1650`)

Emakefun I2C 四位数码管 V1（默认地址 0x70），支持数字/小数显示、冒号、亮度与清屏。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/displayers/TM1650/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_digit_display
- 积木数量：5 块（CK `schema v2` 声明式运行时）
