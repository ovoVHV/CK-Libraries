# Emakefun 五路循迹传感器 V3 (`emakefun_five_line_v3`)

Emakefun 五路循迹传感器 V3.0（I2C 0x50），支持各通道高低阈值设定、模拟量与数字黑线检测。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/sensors/five_line_tracker_v3/five_line_tracker_v3/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_five_line_tracker_v3
- 积木数量：6 块（CK `schema v2` 声明式运行时）
