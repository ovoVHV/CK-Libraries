# Emakefun 语音合成模块 V2 (`emakefun_tts_v2`)

Emakefun I2C 语音合成模块 V2（默认地址 0x40），支持 UTF-8/GBK 文本合成播放、缓存播放与启停控制。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/smart_modules/text_to_speech_synthesizer/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_tts
- 积木数量：5 块（CK `schema v2` 声明式运行时）
