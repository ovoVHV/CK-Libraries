# Emakefun I2C GPIO 扩展板 (`emakefun_gpio_board`)

Emakefun 8 路 I2C GPIO 扩展板（E0-E7，地址 0x24），支持数字输入输出、ADC 采集、12位 PWM 与 E1/E2 舵机控制。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/smart_modules/gpio_expansion_board/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_gpio_expansion_board
- 积木数量：7 块（CK `schema v2` 声明式运行时）
