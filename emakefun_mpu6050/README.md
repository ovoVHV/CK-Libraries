# Emakefun MPU6050 六轴陀螺仪 (`emakefun_mpu6050`)

Emakefun MPU6050 六轴姿态传感器（I2C 0x68），读取偏航/俯仰/横滚欧拉角与三轴加速度。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/smart_modules/mpu6050/detail/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_mpu6050
- 积木数量：4 块（CK `schema v2` 声明式运行时）
