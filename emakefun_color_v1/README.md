# Emakefun 颜色识别传感器 V1 (`emakefun_color_v1`)

Emakefun I2C 颜色识别传感器 V1，直接读取 0-255 范围的 R/G/B 颜色分量。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/smart_modules/color_recognition/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_color_sensor
- 积木数量：4 块（CK `schema v2` 声明式运行时）
