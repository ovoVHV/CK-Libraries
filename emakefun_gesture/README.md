# Emakefun 手势识别传感器 (`emakefun_gesture`)

Emakefun I2C 手势识别传感器（默认地址 0x39），支持左/右/前/后滑、上拉、下压、离开、悬停 8 种手势。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/smart_modules/gesture_recognizer/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_gesture_recognizer
- 积木数量：4 块（CK `schema v2` 声明式运行时）
