# Emakefun ASR 串口语音识别 (`emakefun_asr_serial`)

Emakefun 串口离线语音识别模块（9600bps），支持指令播报、音量调节、唤醒控制与复位。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://github.com/emakefun-arduino-library/em_asr_speech_recognition
- 上游官方库：https://github.com/emakefun-arduino-library/em_asr_speech_recognition
- 积木数量：5 块（CK `schema v2` 声明式运行时）
