# Emakefun 触摸矩阵键盘 V2 (`emakefun_matrix_kbd_v2`)

Emakefun 4×4 I2C 触摸矩阵键盘 V2.0（默认地址 0x50），直接读取 0-9/A-D/*/# 触摸字符。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/base_modules/matrix_keyboard_module_v2.0/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_matrix_keyboard
- 积木数量：2 块（CK `schema v2` 声明式运行时）
