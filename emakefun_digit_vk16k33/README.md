# Emakefun VK16K33 四位数码管 (`emakefun_digit_vk16k33`)

Emakefun VK16K33/XK16K33 I2C 四位数码管 V2（默认地址 0x70），支持数字、小数、冒号、亮度与闪烁控制。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/displayers/4_digit_7_segment_v2.0/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_digit_display_xk16k33
- 积木数量：5 块（CK `schema v2` 声明式运行时）
