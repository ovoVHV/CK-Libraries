# Emakefun MD40 四路电机驱动板 (`emakefun_md40`)

Emakefun MD40 I2C 四路编码/直流电机驱动板（默认地址 0x16），支持直流模式、闭环速度、相对/绝对角度位置与转速脉冲读取。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://github.com/emakefun-arduino-library/em_md40
- 上游官方库：https://github.com/emakefun-arduino-library/em_md40
- 积木数量：9 块（CK `schema v2` 声明式运行时）
