# Emakefun NL50 温度传感器 (`emakefun_nl50_temp`)

Emakefun NL50 模拟温度传感器模块，单引脚读取高精度摄氏温度。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/sensors/temperature_sensor_nl50/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_temperature_sensor_nl50
- 积木数量：2 块（CK `schema v2` 声明式运行时）
