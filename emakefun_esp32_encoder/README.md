# Emakefun ESP32 编码电机 (`emakefun_esp32_encoder`)

Emakefun 官方 ESP32 闭环编码电机驱动库（支持 Arduino-ESP32 3.x），提供 PID 调速、PWM 驱动与转速/脉冲读取。

- 厂商：Emakefun
- 支持架构：`esp32`
- 文档：https://github.com/emakefun-arduino-library/em_esp32_encoder_motor
- 上游官方库：https://github.com/emakefun-arduino-library/em_esp32_encoder_motor
- 积木数量：6 块（CK `schema v2` 声明式运行时）
