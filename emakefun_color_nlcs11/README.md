# Emakefun NLCS11 颜色传感器 (`emakefun_color_nlcs11`)

Emakefun NLCS11 I2C 颜色识别传感器，支持增益与积分时间设置及 R/G/B/C 分量读取。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/smart_modules/NLCS11/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_color_sensor_nlcs11
- 积木数量：6 块（CK `schema v2` 声明式运行时）
