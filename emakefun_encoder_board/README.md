# Emakefun 编码电机驱动板 (`emakefun_encoder_board`)

Emakefun I2C 四路编码电机扩展板（默认地址 0x09），支持速度、PWM、角度定位与实时反馈读取。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://github.com/emakefun-arduino-library/emakefun_encoder_motor_board
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_encoder_motor_board
- 积木数量：7 块（CK `schema v2` 声明式运行时）
