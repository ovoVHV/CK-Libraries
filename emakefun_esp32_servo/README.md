# Emakefun ESP32 舵机驱动 (`emakefun_esp32_servo`)

Emakefun 官方 ESP32 舵机驱动库（基于 ESP32 LEDC），支持 0-180° 角度与微秒脉宽精确控制。

- 厂商：Emakefun
- 支持架构：`esp32`
- 文档：https://github.com/emakefun-arduino-library/em_esp32_servo
- 上游官方库：https://github.com/emakefun-arduino-library/em_esp32_servo
- 积木数量：3 块（CK `schema v2` 声明式运行时）
