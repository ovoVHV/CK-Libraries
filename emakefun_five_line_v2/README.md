# Emakefun 五路循迹传感器 V2 (`emakefun_five_line_v2`)

Emakefun 五路循迹传感器 V2.0（I2C 0x50），支持灵敏度设置、单路模拟值与黑线状态读取。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/sensors/five_way_tracking_sensor_v2.0/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_five_line_tracker
- 积木数量：5 块（CK `schema v2` 声明式运行时）
