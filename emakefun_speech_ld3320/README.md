# Emakefun LD3320 语音识别 V2 (`emakefun_speech_ld3320`)

Emakefun LD3320 I2C 离线语音识别模块（地址 0x30），支持自动/关键词/按键触发及最多 50 条中文拼音关键词。

- 厂商：Emakefun
- 支持架构：`avr, esp32`
- 文档：https://docs.emakefun.com/sensors/smart_modules/speech_recognizer/
- 上游官方库：https://github.com/emakefun-arduino-library/emakefun_speech_recognizer
- 积木数量：6 块（CK `schema v2` 声明式运行时）
